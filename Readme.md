# Mechanical Engineer Portfolio Website

A responsive, single-page personal portfolio website designed and developed for Mechanical Engineer **Batuhan Çanakcı**.

## 🌟 Features
* **Responsive Design:** Compatible with mobile, tablet, and desktop views.
* **Interactive UI:** Smooth scrolling, animated typing effect using `Typed.js`, and side navigation panel.
* **Contact Form Integration:** Functional email form powered by `SmtpJS`.
* **Embedded Google Maps:** Location section integrated for easy reach.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (ES6)
* **Libraries:** FontAwesome 6, Typed.js, SmtpJS
* **Hosting:** GitHub Pages
